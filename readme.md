# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. 
This project allows two players to play against each other in a classic 3×3 grid.

## ✨ Features

- 🎯 Two-player gameplay (O and X)
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Reset game functionality
- 📱 Simple and user-friendly interface
- ⚡ Interactive buttons and smooth gameplay

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
